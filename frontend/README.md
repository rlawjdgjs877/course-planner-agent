# Plann 프론트엔드

경북대학교 컴퓨터학부 학생을 위한 Finder 스타일의 학업 관리 화면입니다.
Next.js App Router, TypeScript, Tailwind CSS로 구현했습니다.

## 실행하기

Node.js와 npm을 설치한 뒤, 저장소 루트에서 실행합니다.

```bash
cd frontend
npm ci
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다. 시간표 생성·AI 채팅·학교 불러오기는 백엔드(http://localhost:8000)가 켜져 있어야 동작합니다. 백엔드 실행법은 저장소 루트의 README를 보세요.
발표용 샘플 학생으로 바로 시작하려면 http://localhost:3000/?demo=1 을 엽니다.
Windows PowerShell에서 npm.ps1 실행 제한이 뜨면 `npm.cmd ci`, `npm.cmd run dev`를 사용하세요.

## 검사와 빌드

```bash
npm run lint
npm run build
npm run start
```

## 환경변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `NEXT_PUBLIC_API_BASE` | `http://localhost:8000` | 백엔드 주소. 배포 시 Render 주소 |
| `NEXT_PUBLIC_PUBLIC_DEMO` | 꺼짐 | `1`이면 공개 체험판: 첫 화면이 "샘플 학생으로 시작 / 이수 과목 직접 체크하기"이고 학교 로그인은 숨김 |

Vercel에서 배포할 때 Root Directory는 `frontend`로 지정하고 위 두 값을 넣습니다.

## 현재 기능

- Finder 스타일 화면, 학년 폴더(열고 닫기), 과목 검색 및 이수 체크
- 학교 로그인으로 이수 과목과 졸업자가진단 불러오기: 학년·전공·입학 연도 자동 채우기, "학교에서 확인한 내 졸업 현황" 카드(교과구분별 기준·이수·부족 학점, 필수과목 이수 여부). 이번 학기 수강 중 과목은 이수로 치지 않음
- 심컴·인컴·첨컴·플솦·글솦별 졸업요건과 선후수 과목 안내
- 시간표 조건(학점, 공강, 비울 시간, 포함·제외 과목, 교양 영역) 설정 → 백엔드 `POST /tools/generate_timetable`로 후보 3개 생성. 부족한 교양 영역과 미이수 필수과목(`priority_courses`)을 자동으로 함께 보냄
- '나의 시간표' AI 에이전트 채팅(`POST /tools/chat`): 이유 설명, 말로 시간표 수정, 에이전트 단계 표시, 바뀐 과목 강조, 선수과목 경고, 졸업 기여도 막대
- 선택 정보는 브라우저 탭 저장소(sessionStorage)에만 두고, 탭을 닫으면 처음부터 시작

PDF에 없는 과목별 학년·학점·강의 시간은 추측하지 않으며, 졸업 가능 여부를 자동 판정하지 않습니다(졸업 현황은 학교 졸업자가진단 결과를 옮겨 보여 줄 뿐입니다).

## 주요 파일

- `app/components/`: 화면 컴포넌트
- `app/lib/`: 과목, 졸업요건, 선후수 관계, 학생 구분 데이터, 백엔드 호출(`api.ts`, `knu-import.ts`), 졸업자가진단 해석(`school-diagnosis.ts`)
- `app/globals.css`: 화면 스타일
- `public/documents/`: 사용자가 제공한 학업 안내 PDF 원문

`node_modules`, `.next`, `.env` 및 개인의 학적·이수 기록은 저장소에 올리지 않습니다.

## 2026년 2학기 JSON 개설 데이터

제공받은 전공·교양 JSON 10개의 816개 조회 항목을 781개 분반, 254개 과목코드로 정리했습니다.
PDF의 기존 과목과 합친 이수 체크 목록은 288개이며 기존 66개 과목의 저장 ID를 유지합니다.
동일 분반의 전공별 학년·이수 구분은 자료별 기록으로 보존합니다.

- 원문: `data/course-sources/*.json` (10개 파일, 원본 그대로 보존)
- 화면용 데이터: `app/lib/data/offerings.json`, `sources.json`, `import-report.json`
- 다시 생성: `python scripts/import-course-data.py`
- 누락·중복 및 참조 검사: `python scripts/validate-course-data.py`

강좌 검색은 전공·교양 분류, 과목·교수·강좌번호, 학년, 요일 필터와 페이지 이동을 지원합니다.
조회 인원은 파일 생성 시점의 값이며 실시간 잔여석이 아닙니다.
수업 시간이 없는 2개 분반은 미기재로 유지합니다.

## 도구 정의 v3.2 참고 반영

최소·목표·최대 학점, 필수/선호 공강·회피 시간, 포함/제외 과목, 선호 교수 조건을 저장하고 JSON으로 내려받을 수 있습니다.
개설 강좌를 직접 시간표에 담으면 시간 충돌·같은 과목 분반 중복·시간 미정을 검사합니다.
자동 생성과 AI 설명은 백엔드에 연결되어 있습니다. 2025 교육과정 학점 계산은 참고용 졸업 기여도로만 보여 줍니다.

반영 범위와 후속 연결 지점: `docs/agent-tools-v3.2-integration.md`.
충돌 검사 테스트: `node --experimental-strip-types scripts/validate-planning.mjs` (Node.js 22 이상).

## 학교 로그인으로 이수 과목 불러오기

첫 화면의 **학교 로그인으로 시작**에서 백엔드 `/import/knu/*`에 연결합니다.
통합정보시스템 아이디·비밀번호를 넣으면 서버가 학교에 로그인해 이수성적과 졸업자가진단을 자동으로 읽고(로그인부터 약 8초), 결과를 확인해 반영합니다. 학교 화면은 보여 주지 않습니다.
반영하면 학년·전공·입학 연도가 학생 정보에 채워지고, 부족한 교양 영역은 시간표 조건에, 미이수 필수과목은 시간표 생성 요청에 들어갑니다. 이름·학번·연락처 같은 개인정보는 받지 않습니다.
졸업자가진단을 한 번도 실행한 적 없는 학생은 불러오기가 '졸업자가진단수행'을 한 번 실행합니다(학교에 실행 기록이 남음).
아이디·비밀번호·연결 토큰·학교 화면은 브라우저 저장소에 저장하지 않습니다.

실행 설정과 저장 범위, 모의 UI 검사 방법은 `docs/school-import.md`를 확인하세요.
로컬 개발은 `localhost:3000` 프론트엔드와 `localhost:8000` 백엔드를 직접 연결하며 Next.js rewrites는 사용하지 않습니다.
이 기능을 사용하려면 백엔드의 선택 의존성 `requirements-import.txt`를 설치해야 합니다(기능은 기본으로 켜져 있고, 공개 배포에서는 `KNU_IMPORT_ENABLED=0`으로 끕니다).

학교 로그인은 첫 화면에서 연결 안내에 동의한 뒤 버튼을 누르면 Plann 안의 대화상자에 자동으로 표시됩니다.
별도의 '학교 화면 열기' 단계는 없으며 닫기 버튼으로 연결을 종료할 수 있습니다.
학교 자체 점검·장애 화면도 그대로 전달되므로 해당 경우에는 학교 서비스 복구가 필요합니다.

학교 로그인 전 개인정보 제공 동의 영역에서 수집·이용과 연결 서버 처리의 필수 항목을 각각 확인해야 합니다.
수집 항목·목적·처리 경로·보관 및 삭제·동의 거부 안내를 펼쳐 볼 수 있으며, 미동의 시에는 직접 입력을 사용할 수 있습니다.
동의 체크는 현재 페이지 메모리에만 두고 재방문 시 다시 확인합니다.
