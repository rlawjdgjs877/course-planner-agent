# 에이전트 도구 정의 v3.2 프론트엔드 반영

참고 문서: 사용자가 제공한 「에이전트 도구 정의 v3.2」.
문서는 설계 참고자료이며 문서 안의 예시 도구 호출을 실제 실행하지 않았습니다.

## 현재 구현

- 대상 학기: 2026년 2학기 수강신청 전 상황.
- 추천 설계의 2025 교육과정 참고 기준과 기존 PDF의 전공별 연도 기준을 구분해 표시.
- 최소·목표·최대 학점, 최소 학점 강제 여부, 필수 공강/선호 공강, 필수/선호 회피 시간.
- 과목코드·분반번호별 포함/제외 조건, 우선 교양 영역, 선호 교수.
- `generate_timetable` 정의와 같은 필드 이름의 JSON 내보내기. 학생 정보·성적·API 키는 포함하지 않음.
- 개설 강좌를 직접 담기/빼기, 실제 시간 구간으로 겹침 검사, 과목코드별 분반 중복 검사.
- 시간이 누락되거나 자료별 시간이 다르면 판정 보류. 접하는 시간 구간(예: 10:30 종료와 10:30 시작)은 겹침으로 처리하지 않음.
- 선수과목은 검증된 required/recommended 데이터가 없어 확인 필요로 표시. PDF 화살표만으로 적격 여부를 단정하지 않음.
- 직접 구성한 시간표의 필수 공강·차단 시간·제외 과목·이수 과목 포함·최소/최대 학점 경고.
- 브라우저에 저장한 이전 목표 학점과 공강 희망을 복원. 예전 공강 희망은 필수 공강이 아닌 선호 시간으로 옮김.
- 서버 세션이 없는 현재는 `base_candidate_id`를 null로 유지. 이전 서버 세션의 후보 ID를 복원하지 않음.

## 주요 코드

- `app/lib/planning.ts`: 조건 타입, 복원·검증, 시간 해석·충돌 검사
- `app/components/planning-settings.tsx`: 조건 입력 및 요청 JSON 내려받기
- `app/components/schedule-preview.tsx`: 직접 담은 분반 검사 결과
- `app/components/course-offerings.tsx`: 강좌 검색과 담기 버튼
- `scripts/validate-planning.mjs`: 시간 경계·중복·미정·이전 설정 복원 검사

```bash
node --experimental-strip-types scripts/validate-planning.mjs
```

## 아직 연결하지 않은 부분

학교 원격 로그인 기반 이수 과목 가져오기를 기존 백엔드 API에 연결했습니다. 자세한 구현은 `school-import.md`를 확인하세요.
백엔드가 F/NP를 제외한 과목코드·과목명·학점·이수구분을 반환하며, 프론트엔드는 성적·로그인 정보·학교 화면을 저장하지 않습니다.
북마클릿은 아직 구현하지 않았고 조회 응답에 이수 학기 정보가 없어 2026-2 수강 중인 항목 제외는 사용자가 확인하도록 안내합니다.

`calc_credits`의 영역별 부족 학점과 2025 트랙별 요건은 검증된 요건 JSON이 필요합니다.
제공된 2026 졸업요건 PDF를 2025 교육과정으로 이름만 바꾸지 않았습니다.

`check_prereq`의 eligible/ineligible은 검증된 선수 규칙이 준비된 뒤 연결합니다.
상한 19학점은 정의서의 기본값이며 학칙으로 검증된 개인 상한이 아닙니다.

현재 팀 백엔드의 API 스키마와 v3.2 도구 스키마는 일치하지 않습니다.
프론트엔드는 자동으로 요청을 보내지 않으며 SDK·LLM 공급자·서버 코드는 변경하지 않았습니다.
향후 서버 결과의 success/partial/infeasible/timeout, optimal, warnings, alternatives를 연결해야 합니다.
직접 담은 분반을 서버가 생성한 tt_001 후보나 CP-SAT 최적해로 표시하지 않습니다.
