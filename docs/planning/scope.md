# 기능 범위: 필수 vs 추가 (초안)

- 마감: 2026-11-24(화) 12:00. 남은 개발 기간 약 7일 (11/17~11/23)
- 기준: **필수 = 시나리오 3개를 데모에서 끝까지 돌리는 데 필요한 것**. 하나라도 빠지면 데모가 안 됨
- 대상: 2026-2 개설강좌, 2025 교육과정, 전 트랙(심화컴퓨팅, 인공지능컴퓨팅, 첨단컴퓨팅연구, 플랫폼SW데이터과학, 글로벌SW융합)

## 1. 필수 (Must)

| 영역 | 기능 | 담당(안) |
|---|---|---|
| 데이터 | 2026-2 개설강좌 정규화: 분반 id, 시간 → 슬롯 변환, 교시↔시각 대응표, 시간 미정·상주캠퍼스 표시 | 조가연·김재영 |
| 데이터 | 졸업 요건 JSON: 5개 트랙의 이수구분 학점, 전공필수 목록·권장 학기 | 조가연·김재영 |
| 데이터 | 선수과목 JSON: 전공 과목 전부, verified 형식 | 조가연·김재영 |
| 데이터 | 교양 영역 매핑: 2026-2 교양 분반에 영역 붙이기 | 조가연·김재영 |
| 데이터 | 데모용 가상 학생 1명 (2학년 심화컴퓨팅, 이수 과목 고정) | 송승록 |
| 입력 | 이수 과목 체크박스 화면 + 학년·트랙 선택 | 프론트 |
| 입력 | 북마클릿 가져오기 (동작 확인 완료, 우리 사이트로 넘기는 부분만) | 프론트 |
| 입력 | 조건 폼 (목표 학점, 공강 요일, 피할 시간대, 꼭 넣을/뺄 과목, 반드시/가능하면 토글) | 프론트 |
| 도구 | search_courses, calc_credits, check_prereq, check_conflict | 김정헌 |
| 도구 | generate_timetable: 강제 제약, 1~5단계 최적화, 후보 최대 3개, base_candidate_id | 송승록 |
| 도구 | 불가능할 때 대안 1~2개 (최소 완화) | 송승록 |
| 에이전트 | Claude 연동: 도구 호출 루프, 첫 결과 요약, 채팅 수정, 시스템 프롬프트 | 송승록·김정헌 |
| 화면 | 시간표 그리드 (3안 탭), 채팅창, 추천 이유·경고 표시 | 프론트 |
| 화면 | "2025 교육과정 기준 참고용" 안내 | 프론트 |

## 2. 추가 (Nice-to-have, 필수가 다 끝난 뒤 순서대로)

| 순위 | 기능 | 이유 |
|---|---|---|
| 1 | 대안 3개 + 완화 비용 튜닝 | 필수는 1~2개면 충분 |
| 2 | 선호 교수, 정원 초과 경고 | 데모에서 한 줄 보여주기 좋음 |
| 3 | 채팅 수정 결과를 그리드에서 변경된 칸 강조 | 시각적 효과 |
| 4 | 시간표 이미지 저장 | 실사용 편의 |
| 5 | 캡처 업로드(Vision)로 이수 과목 읽기 | 북마클릿이 이미 되므로 후순위 |
| 6 | 모바일 화면 대응 | 발표는 PC |
| 7 | solver timeout·최적 미증명 세부 안내 | 데이터 규모상 거의 안 나옴. 필수에서는 status만 처리 |

## 3. 하지 않음 (Out of scope)

| 기능 | 이유 |
|---|---|
| 졸업까지 학기별 로드맵 | 이번 학기 시간표로 범위 확정 |
| 공식 졸업사정 판정 | 참고용 비교만 |
| 성적·평점 활용, 재수강 규칙 | 성적은 쓰지 않는 원칙 |
| 학사시스템 로그인 대행·실시간 크롤링 | 보안·약관. 개설강좌는 학기당 1회 수동 업로드 |
| 2025 외 교육과정 연도 | 데이터 없음 |
| 상주캠퍼스·교직 과목 추천 | 후보 풀에서 제외 |
| 회원가입·로그인 | 세션만으로 충분 |

## 4. 리스크

| 리스크 | 대응 |
|---|---|
| 5개 트랙 졸업 요건 정리가 오래 걸림 | 데모 트랙(심화컴퓨팅)을 먼저 끝내고 검수. 나머지 4개는 같은 형식으로 이어서 |
| 교양 영역 매핑 누락 | 영역 없는 교양은 "영역 미확인"으로 두고 학점 맞추기용으로만 사용 |
| 데모에서 Claude 응답 지연 | 첫 결과는 폼에서 바로 계산, Claude는 요약만. 리허설로 시간 측정 |
